# ORION Frontend

Next.js web application for the ORION Operations Intelligence System.

## Technology Stack
- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State/Data**: React Query / Server-Sent Events (SSE)

## Views (To be built)
1. **Operations Overview**: High-level anomaly monitors, business KPIs, and live system alert banner.
2. **Investigation Timeline**: Step-by-step trace of agent reasoning, statistical evidence charts, and confidence rankings.
3. **Approval Queue**: Human-in-the-loop interactive review for proposed mitigation actions.
4. **Audit Trail**: Immutable event viewer displaying system-wide state transitions, user approvals, and action receipts.

## Getting Started

```bash
cd frontend
npm install
npm run dev
```
Runs the development server on `http://localhost:3000`.
